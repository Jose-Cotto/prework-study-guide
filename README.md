# Prework Study Guide Webpage

## Description

Provide a short description explaining the what, why, and how of your project. Use the following questions as a guide:

This project was built to help boot camp students keep all their notes in one place and study. The project solves the problem of wondering what to study next by giving the user a randomly generated topic to study. During this project I learned the importance of semantics and workflow.

## Usage

Each section contains notes about a certain topic like, HTML, CSS, JavaScript, and Git. When you open the Devtools console, you can see JavaScript at play by listing all the topics learned from prework and gives the user a random topic to study after each page refresh.
